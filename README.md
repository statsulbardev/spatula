## Tentang Spatula

Spatula merupakan aplikasi berbasis website yang bertujuan dalam mengelola laporan mengenai pelayanan yang diberikan BPS di lingkup Provinsi Sulawesi Barat
yang disampaikan oleh pengguna layanan. Sistem ini sekaligus dapat digunakan untuk memberikan rating kepada petugas layanan sebagai apresiasi atas layanan yang
diberikan kepada pengguna layanan.

Sistem ini dikembangkan dengan menggunakan teknologi seperti :

- Framework [Laravel](https://laravel.com/).
- Fullstack [Laravel Livewire](https://laravel-livewire.com/).
- [Bootstrap CSS](https://getbootstrap.com/)
- Mesin Basis Data [MySQL](https://mysql.com/)
- Telegram
- Beberapa Package
